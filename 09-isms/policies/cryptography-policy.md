# Cryptography Policy (ISO 27001 A.8.24)
**Organization:** NovaTech Solutions  
**Status:** Implemented  

## 1. Purpose & Scope
Ensures appropriate and protected use of cryptography across data at rest and data in transit.
## 2. Standards
* Data at rest encrypted using AWS KMS Customer Managed Keys (AES-256).
* Data in transit secured via TLS 1.3 / TLS 1.2 protocols.
