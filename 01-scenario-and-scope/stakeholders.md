# Maraqlı tərəflər

| Tərəf | Gözləntisi | Təhlükəsizlik tələbi |
|---|---|---|
| Rəhbərlik | Biznesin davamlılığı, qanuni uyğunluq | Risklərin idarəsi, hesabatlılıq |
| İşçilər | Təhlükəsiz və sadə iş mühiti | Aydın siyasətlər, təlim |
| Müştərilər | Məlumatlarının qorunması | Şifrələmə, giriş nəzarəti |
| AWS (provayder) | İstifadə şərtlərinə riayət | Shared Responsibility Model |
| Tənzimləyici orqanlar | Məlumatların qorunması qanunlarına uyğunluq | Sübut və audit izi |
